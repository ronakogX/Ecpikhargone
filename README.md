# Education Point Career Institute — Premium Website

A responsive, animated static website for Education Point Career Institute, Khargone.

## Files
- `index.html` — page content, metadata and organization structured data
- `styles.css` — visual system, responsive layout and motion
- `script.js` — mobile navigation, scroll reveal and current year
- `assets/logo.jpg` — supplied institute logo

## Preview locally
Open `index.html` in a browser. The layout works without a build step. Google Fonts are optional; local system fallbacks are included.

## Publish on Cloudflare Pages
Upload the contents of this folder (not the enclosing folder) to the existing Cloudflare Pages project using Direct Upload. Make sure `index.html`, `styles.css`, `script.js` and the `assets` folder are at the project root.

## Notes
- The website uses the phone number and location details supplied for the institute.
- Confirm course availability, class timings, current review count and rating before publishing any updated facts.
- Decorative map artwork links to Google Maps; it is not a live embedded map.
